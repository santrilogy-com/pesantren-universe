# Audio Referensi — Pesantren Universe

Sampel rekaman untuk dinilai Mas (16 Nov 2026). Semua file sudah dipotong jadi
cuplikan ±1–2 menit, format Ogg Vorbis mono 48 kbps (kecuali file MP3 Al-Fatihah
yang disimpan juga sebagai aslinya). Total folder ±1,9 MB.

> **Penting soal lisensi:** hanya file Al-Quran yang lisensinya jelas untuk
> pemakaian non-komersial. Dua file lainnya (Wirid & Nadzom) **lisensinya
> tidak jelas** — hanya untuk didengarkan/dinilai Mas, BUKAN untuk langsung
> dipakai di game sebelum izinnya dipastikan atau diganti rekaman sendiri.

## Ringkasan untuk keputusan Mas

- **Langsung bisa dipakai di game (non-komersial):** hanya **Al-Fatihah (Alafasy)** — via AlQuran Cloud. Surah pendek lain (Al-Ikhlas, An-Nas, Al-Asr, dll.) bisa diambil dengan cara yang sama dari CDN yang sama.
- **Perlu izin dulu / ganti rekaman:** Ratib al-Haddad dan Nadzom Ajurumiyyah — sampel di sini hanya untuk didengar.
- **Paling aman jangka panjang:** rekam sendiri (Mas/ustadz) untuk wirid & nadzom — suaranya jadi khas Pesantren Universe dan tidak ada masalah lisensi sama sekali.
